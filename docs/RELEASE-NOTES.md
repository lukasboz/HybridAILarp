MeetHalfway 0.4.0 (build 5)

- Optional downloaded local AI for preference drafting, with explicit model download, cancellation and removal.
- Email/password accounts, guest linking and verified migration into an existing account.
- Host/member lifecycle controls, editable activities and revocable invitation links.
- Free OSM place discovery with source-reported venue details for host review.
- Explicit sourced-travel ranking and transfer timing through Transitous, with freshness and request limits.
- People, friendship links and direct invitations to shared plans.
- Private confirmed-plan history, calendar export and personal ratings.
- Two/three-stop proposals with cumulative limits and revision-bound unanimous agreement.
- Offline web shell, connectivity notices and live Updates. Background push requires separate activation.

Android requires Android 11+ on ARM64. The small native model is a separate opt-in download of about 345 MB. Web local AI needs a secure WebGPU browser and its separate larger model. Manual planning is available without a model.

Implementation release: static analysis and compilation completed; physical-device and new functional checks are deferred. No reservations or payments are made by this app.
